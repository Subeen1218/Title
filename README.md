# 2023년 산업연관표 분석 웹앱

[웹앱 실행하기](https://subeen1218.github.io/Title/) · [보도자료 요약계수 시뮬레이터](https://subeen1218.github.io/Title/summary.html)

이 웹앱은 교수님 [Sample_IO](https://github.com/profguclass/Sample_IO)의 **원자료 탐색**과 **국내 생산물 최종수요 증가 시뮬레이션**을 유지하면서, 기본부문뿐 아니라 **통합대분류·통합중분류·통합소분류**에서도 분석할 수 있도록 확장한 과제입니다.

한국은행의 2023년 산업연관표를 바탕으로 **어떤 상품이 어느 부문의 생산에 사용됐는지**, **특정 상품의 최종수요가 늘면 그 효과가 어느 부문으로 퍼지는지**를 확인할 수 있습니다.

## 사용 방법

1. **분류 선택:** 통합대분류(33개), 통합중분류(83개), 통합소분류(165개), 기본부문(380개) 중 하나를 선택하고 **자료 불러오기**를 누릅니다.
2. **원자료 탐색:** 시트를 선택한 뒤 원하는 행을 고릅니다. 열 검색을 비워두면 선택한 행의 모든 열이 표시되고, 상품명이나 코드를 입력하면 일치하는 열만 표시됩니다.
3. **최종수요 증가 시뮬레이션:** 수요가 증가하는 상품을 선택하고 증가액을 **백만 원** 단위로 입력한 뒤 시나리오에 추가합니다. 여러 상품을 추가해 함께 계산할 수 있습니다.
4. **결과 확인:** 수요 증가액·생산유발액·수입유발액·부가가치유발액은 상단의 네 결과 박스에서 확인합니다. 아래 그래프와 표는 **생산유발액 상위 15개 부문**을 보여주며, 전체 부문 결과는 CSV로 내려받을 수 있습니다.
5. **부문 비교:** 영향력계수와 감응도계수는 같은 분류 안에서 비교합니다. 노동 지표는 한국은행 공표 부문 기준이며, 세부 상품에 임의로 배분하지 않았습니다.

## 1. 원자료 탐색: 2023년에 어떤 상품이 어디에 쓰였는가?

거래표의 **중간거래 구역**에서 행은 공급된 상품, 열은 그 상품을 중간재로 사용한 생산 부문입니다.

예를 들어 기본부문 국산거래표에서 `0111 · 벼`를 **행**으로 선택하면, 국산 벼가 각 부문의 생산에 중간재로 얼마나 사용됐는지 볼 수 있습니다. 반대로 **벼를 생산하는 데 어떤 상품이 쓰였는지** 알아보려면 벼가 **열**에 와야 합니다. 국산거래표와 수입거래표를 비교하면 투입의 국내·해외 공급을 구분할 수 있고, 투입계수표에서는 산출 1단위당 각 중간재가 직접 얼마나 필요한지 확인할 수 있습니다.

총거래표에서 **벼 행 × 벼 열**의 `110,358백만 원`은 2023년에 벼 부문이 생산 과정에서 중간재로 사용한 벼의 거래액입니다. 이 값은 당시의 거래 규모이지, 벼의 최종수요가 추가로 늘었을 때 유발되는 생산액이 아닙니다.

## 2. 최종수요 증가 시뮬레이션: 수요가 늘면 효과가 어디에 나타나는가?

기본부문 `0111 · 벼`의 국내 최종수요가 **1,000백만 원(10억 원)** 늘어난다고 가정합니다. 입력창에 `1000`을 넣고 시나리오에 추가한 뒤 계산하면 다음과 같습니다.

| 결과 항목 | 금액(백만 원) |
|---|---:|
| 수요 증가액 | 1,000 |
| 생산유발액 | 1,362.024 |
| 수입유발액 | 89.276 |
| 부가가치유발액 | 910.724 |

전체 생산유발액 가운데 **1,014.518백만 원**은 벼 부문 자체에서, **약 347.505백만 원**은 다른 부문에서 유발됩니다. 금액은 계산을 마친 뒤 항목별로 반올림하므로, 화면에 표시된 값을 더한 결과가 전체 합계와 소폭 다를 수 있습니다.

상단 결과 박스는 **전체 부문의 합계**를 보여줍니다. 아래 상위 15개 그래프와 표는 **그 효과가 어느 부문에 크게 나타났는지** 보여줍니다. 예를 들어 벼 자체의 생산 효과와, 벼 생산에 필요한 중간재를 공급하는 다른 부문의 생산 효과를 구분해서 볼 수 있습니다.

원자료의 `9690 · 부가가치계` 행에서 벼 열의 **6,195,806백만 원**은 2023년 벼 부문에서 발생한 부가가치 총액입니다. 반면 **910.724백만 원**은 벼의 최종수요가 10억 원 늘어났다는 가정에서 벼와 관련 부문을 합쳐 추가로 유발되는 부가가치입니다. 두 값은 기준과 범위가 다릅니다.

## 3. 전·후방 연쇄효과: 부문별 파급력을 어떻게 비교하는가?

- **영향력계수(후방연쇄효과):** 특정 상품의 최종수요가 1단위 늘 때 전체 생산을 얼마나 끌어올리는지 나타냅니다. 생산유발계수표의 해당 상품 **열합**을 같은 분류의 평균 열합으로 나눕니다.
- **감응도계수(전방연쇄효과):** 모든 상품의 최종수요가 각각 1단위씩 늘 때 해당 부문의 생산이 얼마나 반응하는지 나타냅니다. 생산유발계수표의 해당 상품 **행합**을 같은 분류의 평균 행합으로 나눕니다.

두 계수 모두 **같은 분류 내 평균이 1**인 지수입니다. 산점도에서 두 기준선의 오른쪽 위에 있는 부문은 두 계수가 모두 평균보다 높습니다.

기본부문 벼의 영향력계수는 **0.696083**, 감응도계수는 **1.393888**입니다. 벼의 수요만 늘렸을 때의 전체 생산 파급력은 기본부문 평균보다 작지만, 모든 상품의 수요가 같은 금액만큼 늘 때 벼 생산의 반응은 평균보다 큽니다.

## 4. 보도자료 요약계수 시뮬레이터: 경제 전체 효과를 빠르게 비교하기

[보도자료 요약계수 시뮬레이터](https://subeen1218.github.io/Title/summary.html)는 한국은행 「2023년 산업연관표(연장표)」 보도자료 PDF 15쪽의 **2023년 공표 계수**를 사용합니다. 원표 엑셀을 불러오지 않고도 건설이나 서비스 같은 요약 부문의 경제 전체 파급효과를 빠르게 비교할 수 있습니다.

예를 들어 수요가 증가하는 부문에서 **건설**을 선택하고, 최종수요 증가액으로 **100백만 원(1억 원)** 을 입력합니다.

| 사용한 요약계수 | 건설의 계수 | 유발액(백만 원) | 해석 |
|---|---:|---:|---|
| 생산유발계수 | 2.029 | 202.9 | 건설과 관련 공급 부문을 합쳐 유발되는 국내 생산액 |
| 부가가치유발계수 | 0.788 | 78.8 | 건설과 관련 공급 부문을 합쳐 유발되는 국내 부가가치 |
| 수입유발계수 | 0.212 | 21.2 | 해당 생산 과정에서 직·간접적으로 유발되는 수입액 |

화면의 **'사용한 요약계수'** 는 최종수요 1단위당 경제 전체에서 얼마가 유발되는지를 나타냅니다. 예를 들어 건설의 생산유발계수 `2.029`는 건설 최종수요가 1원 늘 때 **건설 부문만이 아니라 경제 전체에서** 약 2.029원의 국내 생산이 유발된다는 뜻입니다. 최종수요 증가액에 각 계수를 곱해 유발액을 구하며, 공표 계수가 반올림되어 있으므로 결과는 근사값입니다.

**요약계수 페이지**는 '경제 전체에서 얼마나 유발되는가?'를 빠르게 확인하는 데 쓰고, **메인 화면의 원표 시뮬레이션**은 '어느 부문에서 얼마가 유발되는가?'를 분석하는 데 씁니다. 두 화면에서 이름이 같은 부문을 선택하더라도 자료의 집계 수준이 다르면 결과가 달라질 수 있습니다.

## 자료 출처와 해석 범위

- **원자료:** 한국은행 [「2023년 산업연관표(연장표)」 작성 결과](https://www.bok.or.kr/portal/bbs/B0000501/view.do?menuNo=201264&nttId=10093668), 생산자가격 기준 통합대·중·소분류 및 기본부문 투입산출표.
- **자료 가공:** 공개된 상품·산업별 집계자료를 사용했습니다. 웹앱의 시나리오 결과와 그래프는 원자료를 바탕으로 계산·가공했습니다.
- **단위:** 거래액, 최종수요 증가액, 유발액은 **백만 원**입니다. 투입계수와 유발계수는 각각 산출 1단위와 최종수요 1단위에 대한 비율이며, 영향력·감응도계수는 같은 분류의 평균을 1로 둔 지수입니다.
- **해석 범위:** 시뮬레이션은 2023년의 투입 구조가 유지된다는 가정 아래 계산한 결과입니다. 생산유발액은 매출 전망이나 이익이 아니며, 파급효과가 크다고 해서 투자수익률이 높다는 뜻은 아닙니다.
