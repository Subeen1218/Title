# 산업연관표 분석 웹앱

교수님 [Sample_IO](https://github.com/profguclass/Sample_IO)를 확장했습니다. 자료는 한국은행 2023년 산업연관표(연장표), 생산자가격입니다.

1. 분류를 선택하고 자료를 불러옵니다.
2. 원자료 탐색에서 시트, 행, 열을 검색합니다.
3. 국내 생산물 최종수요 증가액(백만 원)을 상품별로 추가하고 계산합니다. 화면은 생산유발액 상위 15개, CSV는 전체입니다.
4. 영향력·감응도 순위는 같은 분류 내에서 비교합니다. 노동 수치는 공표 부문 기준이며 세부 상품에 배분하지 않습니다.

검산: 기본부문 `0111`에 `100`을 추가하면 생산 `136.202`, 수입 `8.928`, 부가가치 `91.072`백만 원입니다. 표시만 반올림합니다.

GitHub Pages는 main / (root)로 설정합니다. 기존 대·중·소·기본부문 엑셀 4개를 저장소 최상위에 원래 파일명 그대로 둡니다.

Q&A
## 이 웹앱으로 무엇을 알 수 있나요?

이 웹앱은 한국은행의 2023년 산업연관표를 활용해 **산업 간 거래 구조**와
**국내 생산물의 최종수요 증가에 따른 파급효과**를 분석합니다.
통합대분류·통합중분류·통합소분류·기본부문 중 원하는 수준을 선택할 수 있습니다.

### 1. 원자료 탐색: 어떤 상품이 어느 부문에 사용됐는가?

거래표에서는 실제 기준연도의 거래 구조를 확인할 수 있습니다.
중간거래 구역에서 행은 공급된 상품, 열은 그 상품을 생산에 사용한 부문입니다.
예를 들어 기본부문 국산거래표에서 `0111 · 벼` 행을 선택하면,
국산 벼가 각 부문의 생산에 중간재로 얼마나 사용됐는지 확인할 수 있습니다.

반대로 벼 생산에 어떤 상품이 사용됐는지 보려면 벼가 열에 와야 합니다.
국산거래표와 수입거래표를 비교하면 해당 투입이 국산인지 수입인지 구분할 수 있고,
투입계수표에서는 벼를 1단위 생산하는 데 각 중간재가 직접 얼마나 필요한지 볼 수 있습니다.

예를 들어 총거래표의 벼 행·벼 열에 있는 `110,358백만 원`은
2023년에 벼 부문이 생산 과정에서 중간재로 사용한 벼의 거래액입니다.
이는 벼의 최종수요가 증가했을 때 새로 발생하는 생산액이 아닙니다.

### 2. 최종수요 증가 시뮬레이션: 수요가 늘면 어디에 효과가 나타나는가?

기본부문에서 `0111 · 벼`의 국내 생산물 최종수요를 `1,000백만 원(10억 원)`
늘린다고 가정하면, 경제 전체에서 생산 `1,362.024백만 원`,
수입 `89.276백만 원`, 부가가치 `910.724백만 원`이 유발됩니다.

전체 생산유발액 중 `1,014.518백만 원`은 벼 부문 자체에서,
약 `347.505백만 원`은 다른 부문에서 발생합니다.
결과 화면의 상위 15개 그래프와 표를 보면 어떤 부문에 생산 효과가
크게 나타나는지 확인할 수 있습니다. 상단의 합계는 모든 부문을 포함하며,
상위 15개만 합한 금액이 아닙니다.

또한 원자료의 `9690 · 부가가치계` 행에서 벼 열의 `6,195,806백만 원`은
2023년 벼 부문에서 발생한 부가가치 총액입니다. 시뮬레이션의
`910.724백만 원`은 벼의 최종수요를 10억 원 늘린다는 가정에서
벼와 관련 부문을 합쳐 추가로 유발되는 부가가치이므로, 두 값은 직접 비교하지 않습니다.

### 3. 부문 비교: 수요를 늘렸을 때의 파급력과 다른 부문의 수요에 대한 반응

영향력계수로는 한 상품의 최종수요가 늘 때 전체 생산을 끌어올리는 정도를,
감응도계수로는 모든 상품의 최종수요가 같은 금액만큼 늘 때 해당 부문의
생산이 반응하는 정도를 같은 분류 안에서 비교할 수 있습니다.

기본부문 벼의 영향력계수는 `0.696083`, 감응도계수는 `1.393888`입니다.
벼 자체의 수요 증가가 전체 생산을 끌어올리는 정도는 기본부문 평균보다 작지만,
모든 상품의 수요가 함께 늘 때 벼 부문의 생산 반응은 평균보다 크다는 뜻입니다.
따라서 '벼의 수요를 늘리는 경우'와 '여러 부문의 수요가 함께 늘어나는 경우'는
구분해서 해석해야 합니다.

> **해석 범위:** 이 시뮬레이션은 2023년의 투입 구조가 유지된다는 가정 아래
> 파급효과를 비교하는 도구입니다. 생산유발액은 매출 전망이나 이익이 아니며,
> 파급효과가 크다고 해서 투자수익률이 높다는 뜻도 아닙니다.

### 4. 보도자료 요약계수 시뮬레이터: 경제 전체 효과를 빠르게 비교하기

[보도자료 요약계수 시뮬레이터](./summary.html)는 한국은행
「2023년 산업연관표(연장표)」 보도자료 15쪽의 2023년 공표 계수를 사용합니다.
건설이나 서비스 같은 요약 부문을 선택하고 국내 생산물의 최종수요 증가액을
입력하면, 경제 전체에서 유발되는 생산·부가가치·수입을 빠르게 비교할 수 있습니다.

예를 들어 건설의 최종수요를 `100백만 원` 늘린다고 가정하면,
건설과 관련 공급 부문을 합쳐 국내 생산 `202.9백만 원`,
국내 부가가치 `78.8백만 원`, 수입 `21.2백만 원`이 유발되는 것으로 추정됩니다.

화면의 '사용한 요약계수'는 해당 부문의 최종수요 1단위당 경제 전체에서
얼마가 유발되는지를 나타냅니다. 건설의 계수는 생산 `2.029`,
부가가치 `0.788`, 수입 `0.212`입니다. 각 계수에 최종수요 증가액을
곱해 해당 유발액을 구합니다. 공표 계수가 반올림되어 있으므로 결과는 근사값입니다.

요약계수 시뮬레이터는 '경제 전체에서 얼마나 유발되는가?'에 답합니다.
'어느 부문에서 얼마가 유발되는가?'를 보려면 메인 화면의
'국내 생산물 최종수요 증가 시뮬레이션'에서 원표를 불러와
부문별 유발액과 생산유발액 상위 15개를 확인하세요.
